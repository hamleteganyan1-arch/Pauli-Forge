**10. Исправления, без которых старые доказательства использовать нельзя**

- В нормировке \(-\Delta-Z/r\):
  \[
  u=Ce^{-Zr/2},\qquad E=-Z^2/4,\qquad
  B_W=-\tfrac12\Delta+\tfrac{Z^2}{8}-\tfrac Z{2r}.
  \]
- Формула отклика только через occupied–unoccupied переходы требует равных занятостей либо добавления пропущенных occupied–occupied членов.
- Условие \(\operatorname{dist}(\varepsilon_j,\sigma(h|_Q))\ge g\) не обеспечивает положительности резольвенты: нужен **направленный** gap \(h|_Q-\varepsilon_j\ge gI\).
- При \(B=-X^{-1}\) верно \(f=-Bg\). В экспоненциально-взвешенной калибровке также исправляется знак веса.
- Schur-аргумент требует корректных формовых областей и устойчивости проекторов; одного gap недостаточно.
- Старый запрет **любого** надёжного snapshot-индикатора слишком широк. Запрещены заявленные более сильные версии — например двусторонняя эффективность без достаточной информации.
- Инъективность отдельных вкладов не запрещает их взаимную компенсацию. Поэтому старый общий global-scale no-go не принят.
- Предел для двух фиксированных фрагментов не даёт равномерный результат при растущем числе фрагментов.
- Ранняя слабая замкнутость fixed-mass функционала исправляется нормовой \(L^1\)-замкнутостью. Для вырожденного локального поиска нужен мост между relaxed и исходным классами; поздняя D-reg даёт соответствующий контроль.
- Надписи «закрыто» в исторических таблицах не заменяют доказательств и не определяют текущий статус.

**Итог:** эти исправления внесены в оценку результатов выше. Следующий шаг должен использовать исправленные формулировки, а не прежние номера «закрытых задач».
