# Спектральный ремонт перекрытия и граница полиномиального каталога

Дата: 15 октября 2026. Продолжение проекта об ансамблевом Ts.
Статус: ниже доказаны новые оценки для произвольного конечного разложения допустимой плотности. Полиномиальный каталог для всех нейтральных Coulomb-систем не объявляется доказанным.

## 1. Выбор направления

| Путь | Проверяемое условие | Решение на этом шаге |
|---|---|---|
| Геометрический каталог всех физических локальных профилей | Полиномиальная метрическая энтропия | Исключён предыдущим результатом для широкого класса открытых геометрий; энергетическая задача этим не опровергнута |
| Малость всех попарных перекрытий | Малый скаляр Theta | Достаточное, но грубое условие; ранее доказано |
| Ремонт только реально переполненных орбитальных направлений | Положительная часть Gamma-2I | Выбран; конструкция и количественная оценка доказаны ниже |
| Усечение по рангу без контроля функций | Полиномиальное число направлений | Само по себе недостаточно для каталога; различие фиксируется явно |
| Вывод малого спектрального дефекта из физики | Равномерные оценки по N и геометрии | Остаётся следующей физической задачей |

Итог шага: выбран спектральный ремонт. Он заменяет грубую оценку перекрытия проверяемым операторным дефектом. Следующее действие — вывести точную допустимую матрицу и оценить цену ремонта.

## 2. Определения и область утверждений

Работаем на R^3; те же доказательства действуют на кубе с Neumann-формовой областью H^1, используя локальный резервуар из предыдущего отчёта. Все плотности имеют конечную массу и квадратный корень в H^1. Все матрицы положительны, trace-class и имеют конечную невзвешенную кинетическую энергию K.

Для измеримого веса 0<=a<=1 положим
\[
 q_a(\gamma)=\operatorname{Tr}((-\nabla\cdot a\nabla)\gamma),\qquad
 W_a[f]=\int a|\nabla\sqrt f|^2,\qquad I_a[f]=\int a f^{5/3}.
\]
Здесь q понимается как неотрицательная квадратичная форма, включая вырожденный вес.
\[
 F_a[f]=\inf_{\rho_\gamma=f,\ 0\le\gamma\le2I,\ K(\gamma)<\infty}q_a(\gamma),
 \qquad P_a[f]=F_a[f]-W_a[f].
\]
Для a=1 на R^3: F_a=Ts. Локальный P_a[f] не заменяется на P[af].

Пусть
\[
 \rho=\sum_{j=1}^m\rho_j,\quad
 D_a=\sum_jW_a[\rho_j]-W_a[\rho]\ge0.
\]
Выберем допустимые компонентные матрицы gamma_j и обозначим
\[
 \Gamma=\sum_j\gamma_j,\qquad
 e=\sum_j\bigl(q_a(\gamma_j)-F_a[\rho_j]\bigr)\ge0.
\]
Число e — ошибка выбранных компонентных состояний. Оно не исчезает только от наличия точных скалярных меток F_a. Тогда точно
\[
 E_\Gamma:=q_a(\Gamma)-W_a[\rho]
 =\sum_jP_a[\rho_j]+D_a+e. \tag{1}
\]
Матрица Gamma может нарушать ограничение 2I.

Используем доказанный ранее cap-I резервуар: для любой f указанного класса существует R[f] с
\[
 0\le R[f]\le I,\quad \rho_{R[f]}=f,\quad
 q_a(R[f])-W_a[f]\le A I_a[f]+B W_a[f], \tag{2}
\]
где можно взять
\[
 A=2^{2/3}\frac35(6\pi^2)^{2/3},\qquad B=16\pi^2-1.
\]
Это верхняя оценка, а не формула точного минимума.

## 3. Спектральный избыток: конечность и полиномиальный ранг

Определим
\[
 X=(\Gamma-2I)_+.
\]
Если Gamma=sum_l n_l |phi_l><phi_l|, то
\[
 X=\sum_{n_l>2}(n_l-2)|\phi_l\rangle\langle\phi_l|,\qquad
 b=\rho_X=\sum_{n_l>2}(n_l-2)|\phi_l|^2. \tag{3}
\]
Функция b — плотность избыточной заселённости, а не вся перекрывающаяся плотность.

**Теорема 1.** При M=int rho имеем:
\[
 0\le X\le\Gamma,\quad 0\le b\le\rho,\quad
 K(X)\le K(\Gamma),\quad
 W_a[b]\le q_a(X),
 \tag{4}
\]
а число r направлений n_l>2 удовлетворяет
\[
 2r< M\quad\text{при }r>0. \tag{5}
\]
При r=0 имеем X=b=0, включая случай M=0.

**Доказательство.** Спектрально 0< n_l-2<n_l на выбранных направлениях, откуда операторное неравенство. Число n_l>2 конечно, поскольку sum n_l=M. Более точно 2r<sum_{n_l>2}n_l<=M. Это же даёт конечность K(X) через неотрицательную форму -Delta, например сначала для её ограниченных спектральных усечений и затем монотонным пределом.

Диагональная монотонность X<=Gamma следует из положительности Gamma-X: диагонали положительных trace-class операторов неотрицательны почти всюду, а диагональ аддитивна. Поэтому b<=rho. Для фактора Y=(sqrt(n_l-2)phi_l) имеем sqrt b=||Y||. Неравенство для градиента нормы даёт sqrt b in H^1 и W_a[b]<=q_a(X). QED.

**Следствие для прежнего адаптивного атласа.** В каждом локальном блоке с массой M_loc<=M_*(epsilon), где ранее M_*(epsilon)=O(epsilon^{-3/2}), число переполненных направлений
\[
 r<M_{\rm loc}/2=O(\varepsilon^{-3/2}). \tag{6}
\]
Здесь Gamma должна иметь диагональ именно плотности данного блока. Глобальную массу N нельзя подменять локальной M_loc.

Это полиномиальный ранг дефекта, независимо от числа компонент разложения. Это не полиномиальная длина описания phi_l: функции ещё принадлежат бесконечномерному пространству.

**Почему это различие нельзя убрать.** Для любой нормированной неотрицательной phi in H^1 и фиксированного 0<delta<=2 можно взять gamma_1=gamma_2=(1+delta/2)|phi><phi|. Обе компоненты допустимы, а Gamma=(2+delta)|phi><phi|, X=delta|phi><phi| и b=delta phi^2. Итак, даже при r=1 плохое направление может быть произвольной H^1-функцией. Нормы ограничиваются выбором H^1-шара, но число независимых пространственных параметров этим не становится фиксированным. Это пример в общем допустимом классе; принадлежность всех таких плотностей физическому Coulomb-классу не утверждается. Он также не доказывает энергетическую трудность: сложная форма не обязательно означает сложное значение P.

## 4. Точный ремонт при произвольном перекрытии

**Теорема 2.** Для любого t>0 положим
\[
 \eta_t=\rho+b/t,\qquad
 \widetilde\Gamma_t=
 \frac{\Gamma-X+tR[\eta_t]}{1+t}. \tag{7}
\]
Тогда
\[
 \rho_{\widetilde\Gamma_t}=\rho,\qquad
 0\le\widetilde\Gamma_t\le2I,\qquad K(\widetilde\Gamma_t)<\infty. \tag{8}
\]
Дополнительно
\[
 P_a[\rho]\le
 \frac{E_\Gamma+W_a[b]-q_a(X)
       +t\{A I_a[\eta_t]+B W_a[\eta_t]\}}{1+t}. \tag{9}
\]

**Доказательство.** Поскольку sqrt rho и sqrt b принадлежат H^1, норма вектора (sqrt rho,t^{-1/2}sqrt b) показывает, что sqrt eta_t in H^1. Масса eta_t конечна, так что резервуар (2) применим.

Спектральное усечение даёт 0<=Gamma-X<=2I. Поэтому
\[
 0\le\widetilde\Gamma_t\le\frac{2+t}{1+t}I\le2I.
\]
Диагональ числителя равна
\[
 (\rho-b)+t(\rho+b/t)=(1+t)\rho.
\]
Все слагаемые имеют конечную невзвешенную K. Таким образом (8) выполнено точно, без изменения входной плотности.

По линейности формы на положительных trace-class матрицах
\[
 q_a(\widetilde\Gamma_t)-W_a[\rho]
 =\frac{E_\Gamma-q_a(X)+tq_a(R[\eta_t])-tW_a[\rho]}{1+t}.
\]
Неравенство для градиента нормы даёт субаддитивность
\[
 W_a[f+g]\le W_a[f]+W_a[g],\qquad
 tW_a[\eta_t]\le tW_a[\rho]+W_a[b].
\]
Вставляя (2), получаем правую часть (9). Допустимость матрицы позволяет перейти от её энергии к F_a. QED.

Если X=0, никакой ремонт не нужен: сама Gamma допустима, и
\[
 P_a[\rho]\le\sum_jP_a[\rho_j]+D_a+e. \tag{10}
\]
Известная супераддитивность, также воспроизведённая ниже, даёт обратную границу sum P_a[rho_j]<=P_a[rho].

**Что здесь существенно.** Большие интегралы sqrt(rho_i rho_j) не вынуждают X быть большим. Реальный cap-дефект зависит от относительных орбитальных направлений, а не только от диагоналей.

## 5. Явная энергетическая цена

Положим c=2^{2/3} и
\[
 H=cA I_a[\rho]+B W_a[\rho],\qquad J=cA I_a[b]. \tag{11}
\]
Тогда
\[
 \boxed{
 0\le P_a[\rho]-\sum_jP_a[\rho_j]
 \le D_a+e+2H^{2/5}J^{3/5}+B W_a[b].
 } \tag{12}
\]
Если J=0, член H^{2/5}J^{3/5} полагается нулевым. При a=0 всё тривиально.

**Доказательство верхней границы.** Для x,y>=0:
\[
 (x+y)^{5/3}\le2^{2/3}(x^{5/3}+y^{5/3}).
\]
Следовательно
\[
 tI_a[\rho+b/t]\le c(tI_a[\rho]+t^{-2/3}I_a[b]),
\quad
 tW_a[\rho+b/t]\le tW_a[\rho]+W_a[b].
\]
В (9) используем W_a[b]-q_a(X)<=0. Числитель после этого неотрицателен. Можно убрать делитель 1+t, а затем (1) даёт
\[
 P_a[\rho]-\sum_jP_a[\rho_j]
 \le D_a+e+Ht+Jt^{-2/3}+B W_a[b] \quad(t>0). \tag{13}
\]
Если H,J>0, берём t=(J/H)^{3/5}; сумма двух t-членов равна 2H^{2/5}J^{3/5}. Это удобный выбор, а не заявление о точной оптимальной константе.
Если J=0, пускаем t downarrow0. Если H=0, то из b<=rho следует J=0. Все остальные члены конечны. Верхняя граница доказана.

**Самостоятельная проверка нижней границы.** Для любой допустимой gamma плотности rho возьмём спектральный H^1-фактор Y, ||Y||=sqrt rho=u, и u_j=sqrt rho_j. При u>0 положим h_j=u_j/u, на u=0 — ноль. Факторы Y_j=h_jY принадлежат H^1: отображение (z,r) в проекцию z на замкнутый шар радиуса max(r,0) липшицево и при r<=||z|| даёт rz/||z||. Соответствующие матрицы gamma_j=M_hj gamma M_hj имеют cap2 и диагонали rho_j. Для вещественного радиального направления:
\[
 \sum_k(\|\partial_kY_j\|^2-|\partial_ku_j|^2)
 =h_j^2\sum_k(\|\partial_kY\|^2-|\partial_ku|^2).
\]
Равенство следует из цепного правила и Re<Y/u,partial_k(Y/u)>=0; на u=0 слабые производные исходных H^1-факторов равны нулю почти всюду. Умножение на a, суммирование и sum h_j^2=1 на rho>0 дают sum P_a[rho_j]<=q_a(gamma)-W_a[rho]. Инфимум по gamma завершает доказательство (12). QED.

Формула не требует существования минимизаторов компонент. Она верна для любых выбранных допустимых состояний с явно сохранённой ошибкой e. Из этого нельзя убрать e и одновременно оставить b фиксированным: b зависит от самих выбранных состояний.

## 6. Достаточный экстенсивный сертификат

Предположим на рассматриваемом классе
\[
 I_a[\rho]\le C_5N,\qquad W_a[\rho]\le C_KN.
\]
Обозначим C_H=cAC_5+BC_K. Если для выбранного разложения и выбранных состояний
\[
 D_a+e\le dN,\quad
 I_a[b]\le \zeta^{5/3}N,\quad
 W_a[b]\le \zeta N, \tag{14}
\]
то из (12) непосредственно
\[
 \boxed{
 0\le P_a[\rho]-\sum_jP_a[\rho_j]
 \le \{d+C_{\rm rep}\zeta\}N,\qquad
 C_{\rm rep}=2C_H^{2/5}(cA)^{3/5}+B.
 } \tag{15}
\]
Степени N здесь проверяются точно: (N)^{2/5}(N)^{3/5}=N. Поэтому выбор d=epsilon/2, zeta=epsilon/(2C_rep) даёт ошибку <=epsilon N.

Условие малой массы int b само по себе не заменяет (14): оно не задаёт нужных градиентных и L^{5/3} оценок. Малый ранг также не задаёт этих норм. Теорема (15) достаточна; необходимость именно этих трёх оценок не заявляется.

**Проверка масштабирования.** Для f_L(x)=L^{-3}f(x/L) имеем I[f_L]=L^{-2}I[f] и W[f_L]=L^{-2}W[f]. Оба H и J имеют масштаб энергии L^{-2}; смешанный член H^{2/5}J^{3/5} масштабируется также как L^{-2}. Поэтому формулу можно применять в прежних масштабированных локальных кубах.

## 7. Пример: плотности перекрываются, но переполнения нет

Возьмём нормированные вещественные ортогональные функции phi_0,phi_1 in H^1(R^3) с перекрывающимися носителями; например Gaussian-основное состояние и первое Hermite-состояние. Положим
\[
 \rho_j=2|\phi_j|^2,\qquad
 \gamma_j=2|\phi_j\rangle\langle\phi_j|.
\]
Для вещественной phi_j выполнено W[rho_j]=2 int|grad phi_j|^2, поскольку |grad|phi_j||=|grad phi_j| почти всюду. Значит gamma_j минимизирует компонентный constrained search, P[rho_j]=0 и e=0.

Но
\[
 \Gamma=2\bigl(|\phi_0\rangle\langle\phi_0|+
                    |\phi_1\rangle\langle\phi_1|\bigr)\le2I,
\]
так что X=b=0, хотя int sqrt(rho_0 rho_1)>0. Получаем
\[
 0\le P[\rho_0+\rho_1]\le D.
\]
Это проверяет, что спектральный ремонт может вообще отсутствовать при ненулевом плотностном перекрытии. Малость D этим примером не утверждается.

## 8. Дополнительная необходимая оценка на разложения

Этот раздел объясняет независимость затрат на разделение D и на спектральное переполнение.

Пусть rho>0, N=int rho, и для взвешенной меры rho dx имеется Poincare-оценка
\[
 \int\rho|h-\bar h|^2\le\lambda^{-1}\int\rho|\nabla h|^2,\qquad
 \bar h=N^{-1}\int\rho h,\quad \lambda>0. \tag{16}
\]
Она должна быть доказана для рассматриваемой плотности; для широкого физического класса здесь не постулируется равномерная lambda. Предполагаем применимость (16) к h_j=sqrt(rho_j/rho), например при локально положительном регулярном rho и конечном D.

Пусть
\[
 \mu_j=\int\rho_j,\quad M_0=\max_j\mu_j,\quad
 S_{ij}=\int\sqrt{\rho_i\rho_j},\quad
 \Theta=\max_i\sum_{j\ne i}S_{ij}.
\]
Тогда
\[
 \boxed{D\ge\lambda\,(N-M_0-\Theta)_+.} \tag{17}
\]

**Доказательство.** В L^2(rho dx) рассмотрим конечную систему h_j. Её Gram-матрица равна S, диагональ S_jj=mu_j. По неравенству 2|v_iv_j|<=|v_i|^2+|v_j|^2 имеем ||S||<=M_0+Theta. Оператор T=sum |h_j><h_j| имеет ту же ненулевую спектральную норму. Для нормированной константы e_0=1/sqrt N:
\[
 \sum_j|\langle e_0,h_j\rangle|^2
 =\langle e_0,Te_0\rangle\le M_0+\Theta.
\]
По (16), суммируя по j и используя sum||h_j||^2=N:
\[
 D=\sum_j\int\rho|\nabla h_j|^2
 \ge\lambda\left(N-\sum_j|\langle e_0,h_j\rangle|^2\right)
 \ge\lambda(N-M_0-\Theta).
\]
Также D>=0. QED.

Здесь S — Gram-матрица вещественных амплитуд разложения. Это другая матрица, чем Gamma компонентных квантовых состояний; отождествлять их нельзя.

## 9. Откуда взят резервуар: проверка констант

Чтобы новое утверждение не зависело от неподтверждённой ссылки, воспроизведём конструкцию (2). Положим g(s)=sqrt2 sin(pi(s-1)) на [1,2], ноль вне; int g^2=1. Пусть E_t — Fourier-проектор на шар |p|<(6pi^2t)^{1/3}, так что cap I, диагональ t и кинетическая диагональ c_1 t^{5/3}, c_1=(3/5)(6pi^2)^{2/3}. На кубе берётся его сжатие, сохраняя локальную диагональ и локальную форму.

Для f>=0 определим v_t(x)=g(t/f(x)), ноль при f=0, и
\[
 R[f]=\int_0^\infty M_{v_t}E_tM_{v_t}\,\frac{dt}{t}.
\]
Положительность и Tonelli дают:
\[
 \rho_{R[f]}=\int_0^\infty v_t^2\,dt=f,\quad
 R[f]\le\int_0^\infty M_{v_t^2}\,\frac{dt}{t}
 =\left(\int_1^2g(s)^2\,\frac{ds}{s}\right)I\le I.
\]
Вещественность v_t обнуляет смешанный Fourier-член; поэтому
\[
 q_a(M_{v_t}E_tM_{v_t})
 =t\int a|\nabla v_t|^2+c_1t^{5/3}\int av_t^2.
\]
Заменяя t=sf(x), получаем
\[
 \int_0^\infty|\nabla v_t|^2dt
 =4|\nabla\sqrt f|^2\int_1^2s^2|g'(s)|^2ds
 \le16\pi^2|\nabla\sqrt f|^2,
\]
\[
 \int_0^\infty t^{2/3}g(t/f)^2dt
 =f^{5/3}\int_1^2s^{2/3}g(s)^2ds\le2^{2/3}f^{5/3}.
\]
Отсюда q_a(R[f])<=A I_a[f]+16pi^2 W_a[f], что после вычитания W_a[f] равно (2).

Для фиксированного t функция v_t является Lipschitz-функцией sqrt f, обнуляется вне слоя sqrt(t/2)<=sqrt f<=sqrt t и имеет конечную L^2-норму. Следовательно формовые вычисления законны. Общая невзвешенная K конечна по той же оценке с a=1; конечность I[f] следует из H^1-интерполяции. Интегралы положительных операторов определяются сначала с усечением t, затем монотонным предельным переходом.

Источник слоевой идеи: M. Lewin, E. H. Lieb, R. Seiringer, “The Local Density Approximation in Density Functional Theory”, arXiv:1903.04046v2, §3.2, https://arxiv.org/abs/1903.04046 . Авторство этой исходной конструкции не заявляется. Новые формулы ремонта в настоящем тексте выведены непосредственно из (2).

| Обосновать независимое препятствие для разложения | Доказано условно на проверенную Poincare-оценку | Формула (17); равномерная физическая lambda не доказана |
| Вывести малые D,e,I[b],W[b] из Coulomb-структуры | Открыто | Одних прежних экстенсивных бюджетов для этого вывода пока нет |
| Декодировать хорошие компонентные состояния из одной плотности | Открыто | Скаляры P[rho_j] не определяют их орбитальные факторы |
| Полиномиально описать плохие направления | Открыто | Полиномиальный ранг не ограничивает стоимость описания функций |
| Получить полиномиальную offline-разметку и runtime | Открыто | Их не следует приписывать формуле ремонта |
| Доказать или опровергнуть широкую ML-гипотезу | Открыто | Настоящий шаг не закрывает исходную гипотезу |

Итог шага: доказан точный спектральный ремонт при существенном перекрытии, явная энергетическая оценка и полиномиальный локальный ранг дефекта. Следующая конкретная задача — построить density-only алгоритм выбора компонентных состояний с одновременно малой ошибкой e, малым D и оценками (14), а также полиномиальной длиной описания направлений. Если эти оценки не следуют из выбранного физического разложения, потребуется контрпример для этого разложения или другой энергетический механизм; он не подменяется геометрическим каталогом.
